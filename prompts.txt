Напиши мне функцию findApartmentWithAI, которая принимает на вход строку с полным описанием квартиры и возвращает объект с данными о квартире.

Используй библиотеку openai с фичей Function Calling.
В функции используй модель gpt-4o-mini.

В функции используй структуру JSON с полями:
- cityUUID (string) - UUID города (Астана, Алматы, Актау, Атырау, Караганда, Шымкент)
- propertyClasses (string[]) - классы недвижимости (Комфорт, Бизнес, Премиум, Стандарт и др.)
- propertyTypes (string[]) - типы недвижимости (Квартира, Boxrooms, Коттеджи, Офисы, Паркинги)
- roomCounts (number[]) - количество комнат (1-5)
- priceInMillionMin (number) - минимальная цена в миллионах (12-439)
- priceInMillionMax (number) - максимальная цена в миллионах (12-439)
- floorMin (number) - минимальный этаж (1-25)
- floorMax (number) - максимальный этаж (1-25)
- squareMin (number) - минимальная площадь в м² (28.04-276.22)
- squareMax (number) - максимальная площадь в м² (28.04-276.22)
- isNotFirstFloors (boolean[]) - не первые этажи
- isNotLastFloors (boolean[]) - не последние этажи
- repairs (boolean[]) - наличие ремонта
- readies (boolean[]) - готовность объекта
- readyYears (number[]) - годы готовности (2022-2026)
- readyQuarters (number[]) - кварталы готовности (1-4)
- bigvilleUUIDs (string[]) - UUID комплексов
- placementLayoutTypes (string[]) - типы планировок (Линейка, Пистолет, Бабочка и др.)

Все возможные параметры для поиска квартир находятся в файле filters.json.
